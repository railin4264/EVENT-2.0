# EVENT NOW 2.0 - Local Unofficial Activities (EventConnect v4)

## Visión del Proyecto
Terminar y pulir el proyecto EventConnect (EVENT NOW 2.0) para que funcione de manera impecable ("de punto"). La aplicación debe enfocarse en ser una herramienta global extremadamente útil para encontrar actividades locales, especialmente aquellas que son extra-oficiales o comunitarias, permitiendo a los usuarios descubrir eventos que normalmente no aparecen en carteleras formales.

## Objetivos Actuales (Terminar el Proyecto)
1. Revisar y pulir la arquitectura existente para asegurar que todo funcione sin errores.
2. Implementar un Feed o sección destacada para "Actividades Locales Extra-oficiales".
3. Asegurar que las funcionalidades pendientes esenciales se finalicen para un lanzamiento de producción.
4. Realizar pruebas exhaustivas en Frontend y Backend para garantizar estabilidad.

## Requerimientos Específicos
- **Funcionalidad de Descubrimiento de Eventos Extra-Oficiales**: Una vista o filtro específico que resalte eventos comunitarios, reuniones informales y actividades locales no oficiales.
- **Geolocalización Optimizada**: Mejorar la precisión y la experiencia de usuario al buscar eventos "cerca de mí".
- **Estabilidad General**: Solucionar cualquier bug en la interfaz o en la API que impida el uso fluido de la aplicación.
- **Preparación para Producción**: Asegurarse de que el pipeline de Docker y CI/CD esté configurado correctamente para el despliegue.

## Stack Técnico
- **Frontend**: Next.js App Router, React, Zustand, React Query
- **Mobile**: React Native, Expo
- **Backend**: Node.js REST API, WebSockets
- **Despliegue**: Docker, Docker Compose

## Entregables
- Implementación de la nueva funcionalidad de filtrado y descubrimiento de actividades extra-oficiales.
- Corrección de bugs detectados en el sistema actual.
- Verificación QA de que la aplicación funciona correctamente.
